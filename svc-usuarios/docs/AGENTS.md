# Instruções para agentes

Leia [`agent.md`](agent.md), [`knowledge.md`](knowledge.md) e [`SERVICE.md`](SERVICE.md) antes de alterar o serviço. Preserve os contratos atuais, o isolamento por tenant/escritório e as regras de autorização. Não altere outros microserviços nem o schema compartilhado sem necessidade justificada e migração versionada.
